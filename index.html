Compétences:

HTML est un langage de balisage utilisé pour structurer les pages web. Je l'utilise pour créer des sites internet et organiser leur contenu.

CSS permet de personnaliser l'apparence des pages web : couleurs, polices, animations et mise en page. Je l'utilise notamment pour le design de mon portfolio.

Git est un outil de gestion de versions qui permet de suivre les modifications d'un projet. GitHub permet d'héberger des dépôts et de collaborer sur du code.

Linux est un système d'exploitation très utilisé dans les serveurs et la cybersécurité. Je développe mes compétences dans l'utilisation du terminal, des commandes et de l'administration système.

Je m'intéresse au fonctionnement des réseaux informatiques : adressage IP, protocoles TCP/IP, DNS, routage et communication entre les équipements.

SQL est un langage permettant d'interagir avec des bases de données relationnelles. Il permet notamment de rechercher, ajouter, modifier et supprimer des données.

Python est un langage de programmation polyvalent utilisé pour le scripting, l'automatisation et la cybersécurité. Je l'utilise pour apprendre à développer des programmes et automatiser certaines tâches.
