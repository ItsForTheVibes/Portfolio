# Portfolio

Ce projet est mon portfolio personnel, réalisé en **HTML et CSS**.

- **HTML** : structure les différentes sections du site.
- **CSS** : gère le design, les couleurs et la mise en page.
- **GitHub Pages** : permet d'héberger le site gratuitement.

Le site permet de naviguer entre les différentes sections pour découvrir mon profil, mes compétences et mes projets.
