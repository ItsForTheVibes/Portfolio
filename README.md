## Fonctionnalités du portfolio

- Interface responsive adaptée aux ordinateurs, tablettes et smartphones.
- Design sombre avec des accents bleu cyan.
- Barre de navigation avec mise en évidence de la section active.
- Barre de progression indiquant le défilement de la page.
- Animations d'apparition des sections.
- Accordions Bootstrap pour présenter les compétences.
- Cartes de projets avec descriptions interactives.
- Timeline pour les expériences et le parcours.
- Mini-terminal affichant différents domaines d'intérêt.
- Bouton permettant de copier l'adresse email.
- Bouton de retour en haut de page.
- Prise en compte des préférences de réduction des animations.
